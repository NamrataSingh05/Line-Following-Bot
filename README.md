# Line-Following-Bot
Developed an autonomous line-following robot using ESP32, IR sensor arrays, and PID control for accurate path tracking. Designed a custom PCB and implemented real-time motor control using PWM.

# Autonomous PID Line Follower Robot

## Overview
A high-speed line follower robot built using ESP32 and a 16-channel IR sensor array.

The robot uses PID control to accurately follow a track while maintaining high speed and stability.

## Components Used
- ESP32 Dev Board
- TB6612FNG Motor Driver
- 16-Channel Analog IR Sensor Array
- N20 Encoder Motors
- LiPo Battery

## Features
- PID-based line tracking
- High-speed operation
- Smooth corner handling
- Real-time sensor processing

## Technologies
- Embedded C++
- ESP32
- PID Control
- Robotics

## Results
The robot successfully follows tracks with high accuracy and minimal oscillations.
